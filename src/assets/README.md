# Assets

원작 리소스, 카드 일러스트, 캐릭터명, 스토리 자산은 이 프로젝트에 포함하지 않는다.

카드 이미지는 Phase 9에서 독자 카드 데이터와 독자 에셋을 바탕으로 생성한다. 룰 처리는
이미지에 합성된 텍스트가 아니라 `CardDefinition` 원본 데이터를 기준으로 수행한다.

Phase 9 카드 에셋은 2:3 비율을 기준으로 한다. 정적 WebP에는 프레임과 일러스트 창만
생성하고, 게임 중 변하는 코스트, 지배력, 공격력, 체력/HP는 manifest의 overlay 좌표를
기준으로 Phaser `BitmapText`가 표시한다.

스킬 텍스트는 기본 프레임에 전용 패널을 만들지 않고, Phaser UI에서 일러스트 위 반투명
overlay 레이어로 표시한다.
