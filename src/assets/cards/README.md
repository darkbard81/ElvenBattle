# Card Assets

이 디렉터리는 Phase 9 카드 에셋 파이프라인의 독자 원천 자료와 렌더링 규격을 둔다.

- 기본 카드 프레임은 2:3 비율을 기준으로 한다.
- 기준 작업 크기는 1024 x 1536 px, 축소 출력 크기는 512 x 768 px이다.
- 게임 중 변하는 숫자는 카드 이미지에 굽지 않고 Phaser `BitmapText` overlay로 표시한다.
- 스킬 텍스트는 기본 프레임에 전용 패널을 만들지 않고 일러스트 위 반투명 overlay로 표시한다.
- 원작 이미지, UI, 심볼, 캐릭터, 스토리 리소스는 포함하지 않는다.
