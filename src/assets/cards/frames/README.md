# Card Frames

카드 프레임 초안과 기준 프레임 이미지를 둔다.

- `base-frame-fullart-overlay-01.png`: 풀 일러스트 영역과 런타임 숫자 배지를 가진 현재 기준 초안
- `base-card-back-fullart-01.png`: 현재 기준 프레임과 맞춘 2:3 카드 뒷면 초안
- `base-frame-default-01.png`: 하단 텍스트 패널이 있던 이전 검토 초안
- `base-frame-draft-01.png`: 초기 풀 일러스트 프레임 검토 초안

실제 생성 파이프라인은 코드 기반 SVG 렌더러와 manifest 좌표를 기준으로 동작한다.
